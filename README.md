## Italiano

Repository di addon per Kodi 19 o superiore. Installandolo puoi installare gli addon elencati qui sotto e ricevere i loro aggiornamenti.

### Addon disponibili

| Addon | Descrizione |
|-------|-------------|
| FollowMe | Sposta la riproduzione su un altro Kodi della rete di casa. |

### Installazione

1. In *Impostazioni → Sistema → Add-on* attiva **Origini sconosciute**.
2. In *Impostazioni → Gestore file → Aggiungi sorgente* inserisci `https://fabpolli.github.io/repository.fabpolli/` e dai un nome alla sorgente, ad esempio `fabpolli`.
3. In *Add-on → Installa da file zip* scegli la sorgente `fabpolli` e poi `repository.fabpolli-1.0.0.zip`.
4. In *Add-on → Installa da repository → fabpolli Repository* scegli l'addon da installare.

In alternativa scarica lo zip da [questo link](https://fabpolli.github.io/repository.fabpolli/repository.fabpolli-1.0.0.zip) e installalo con *Installa da file zip*.

## English

Add-on repository for Kodi 19 or later. Once it is installed, you can install the add-ons listed below and receive their updates.

### Available add-ons

| Add-on | Description |
|--------|-------------|
| FollowMe | Moves playback to another Kodi on your home network. |

### Installation

1. In *Settings → System → Add-ons*, enable **Unknown sources**.
2. In *Settings → File manager → Add source*, enter `https://fabpolli.github.io/repository.fabpolli/` and give the source a name, for example `fabpolli`.
3. In *Add-ons → Install from zip file*, choose the `fabpolli` source and then `repository.fabpolli-1.0.0.zip`.
4. In *Add-ons → Install from repository → fabpolli Repository*, choose the add-on to install.

Alternatively, download the zip from [this link](https://fabpolli.github.io/repository.fabpolli/repository.fabpolli-1.0.0.zip) and install it with *Install from zip file*.
